# Portafolio · Miguel Blasquez

Sitio estático (HTML + CSS + JS), sin dependencias ni build.

## Editar datos
Abre `script.js` y completa el objeto `CONFIG` (correo, GitHub, LinkedIn, WhatsApp, CV, foto y proyectos).
Los botones sin valor se ocultan solos.

- Foto: guárdala como `assets/foto.jpg` y pon `photo: "assets/foto.jpg"`.
- CV: guárdalo como `assets/CV-Miguel-Blasquez.pdf` y pon `cv: "assets/CV-Miguel-Blasquez.pdf"`.
- Fechas de experiencia: en `index.html`, dentro de cada `timeline__meta`, agrega
  `<span class="timeline__date">2025 — Presente</span>`.

## Ver en local
Abre `index.html` en el navegador.

## Publicar en GitHub Pages (gratis)
1. Crea un repositorio público llamado `TU-USUARIO.github.io`.
2. Sube estos archivos a la rama `main`.
3. En unos minutos estará en `https://TU-USUARIO.github.io`.

Alternativas: arrastrar la carpeta en https://app.netlify.com/drop o importar el repo en Vercel.
